# ShaaleSync - Digital Asset Auditor 🛡️

ShaaleSync is a professional, mobile-first Android application built in Kotlin to help primary and secondary schools manage, track, and audit their assets effectively. From sports kits and lab equipment to tablets and furniture, ShaaleSync ensures every resource is accounted for.

## 📱 Features

- **Dashboard Overview**: Real-time insights into total assets, active students, available items, and missing/lost equipment with visual trend charts.
- **Asset Inventory**: Vertical list of rich asset cards showing status, location, and category at a glance.
- **Student Database**: Manage student permissions and track exactly which assets are assigned to which student.
- **Quick Audit Mode**: High-speed "Monthly Health Check" that allows teachers to update 10+ items in under 2 minutes.
- **Barcode/QR Scanner**: Integrated scanner using ML Kit to instantly identify and verify equipment.
- **Photo Documentation**: Use CameraX to capture condition photos of high-value items during registration.
- **Professional Reporting**: One-tap "Export Report" feature to share inventory summaries via WhatsApp, Email, or other platforms.
- **Issue Logging**: Dedicated status tracking (Green, Yellow, Red, Missing) with date-stamped notes for lost or damaged items.

## 🛠️ Technical Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose (Material 3)
- **Architecture**: MVVM (ViewModel, Flow)
- **Local Storage**: Room Persistence Library (SQLite)
- **Image Handling**: CameraX & Coil
- **Intelligence**: ML Kit for Barcode Scanning
- **Navigation**: Navigation Compose

## 🚀 Getting Started

### Prerequisites
- Android Studio Ladybug or newer
- Android device or emulator running API 24+

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/piyushpcs/ShaaleSync.git
   ```
2. Open the project in Android Studio.
3. Build the project and run it on your device.
